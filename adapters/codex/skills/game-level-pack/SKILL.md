# Viber Game Level Pack

Read and follow `../viber-mode/packs/vibermode/workflows/game/level-pack.md`.

Default target when unspecified:
- `/Users/mcan/game-with-water`

Rules:
- Work on one selected level-based prototype.
- Add or tune a small coherent level pack.
- Give every changed level an intent, progression dimension, player behavior, and fairness check.
- Add fairness/solvability checks.
- Keep all levels playable from the level map during tuning unless the user asks for locked progression.
- Apply `game-production-quality-gate.md`; full-production/new-game level work must reach 20 meaningful levels or mark the pass blocked/incomplete.
- Validate tutorial/early, middle, and late representative levels with tests or deterministic simulation.

End with level count, curve dimensions, changed level files, tests, validation, and remaining tuning risks.
