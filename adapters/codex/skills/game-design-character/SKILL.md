# Viber Game Design Character

Read and follow `../viber-mode/packs/vibermode/workflows/game/design-character.md`.

Default target when unspecified:
- `/Users/mcan/game-with-water`

Rules:
- Work on one selected prototype.
- Improve identity, states, motion, and readability.
- Name the iconic hook and what existing visual pattern is being avoided.
- Create or update `[prototype-id]-reference-benchmark.md` with current public game references, in-repo comparisons, and final screenshot reference-fit status.
- Do not make meaning color-only.
- Keep rules stable unless visual state requires a small model hook.
- Capture before/after screenshots when practical.
- Apply `game-production-quality-gate.md`; if public references, screenshots, simulator visual inspection, or final reference-fit comparison are blocked, cap the score or mark the design gate blocked instead of claiming completion.

End with the identity direction, reference benchmark status, changed surfaces, screenshots, validation, and next polish risk.
