# Viber Game Visual Novelty Audit

Read and follow `../viber-mode/packs/vibermode/workflows/game/visual-novelty-audit.md`.

Default target when unspecified:
- `/Users/mcan/game-with-water`

Rules:
- Compare against recent prototypes and screenshots when practical.
- Name repeated visual patterns directly.
- Do not change core rules.
- Route low novelty to `viber-game-design-character`.
- Apply `game-production-quality-gate.md`; do not give novelty above 7 without current visual inspection and at least two recent prototype comparisons.

End with novelty score, screenshots inspected, repeated elements, distinct elements, required design changes, and the exact next design-character prompt.
