# Viber Game Grow Best

Read and follow `../viber-mode/packs/vibermode/workflows/game/grow-best.md`.

Default target when unspecified:
- `/Users/mcan/game-with-water`

Rules:
- Do not create a new prototype.
- Choose one existing prototype unless the user names one.
- Improve one coherent layer only.
- Keep levels directly playable during tuning.
- Prefer focused tests first, final validation at the end.
- Apply `game-production-quality-gate.md` when judging whether the growth actually improved fun, readability, level curve, or design identity.
- If the pass touches design, first-read, feedback, or quality scoring, create/update `[prototype-id]-reference-benchmark.md` and compare the final screenshot against public references.
- If the highest-ROI issue is generic design, missing screenshot evidence, weak levels, or missing result/progress shell, fix that before adding another mechanic.

End with the chosen prototype, why it was selected, what changed, validation evidence, screenshots if captured, and the next modular workflow prompt.
